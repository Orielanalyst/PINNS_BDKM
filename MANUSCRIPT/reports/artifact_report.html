Every “verified” family passed two independent gates: exact symbolic vanishing of the closure certificate with free parameters kept symbolic, and 50-digit-precision residuals of the original complex PDE on a dense grid plus random points (max |F| < 10−47, most ≈ 10−50).

§1 · The claimWhat the paper asserts

The paper studies the envelope equation

Az + (i/2)(β₂ + i g₀T₂²)Att + (β₃/6)Attt + (iβ₄/24)Atttt + i(γ + iα₂/2) |A|²A/(1+Γ|A|²) + ½(g₀−α)A = 0

and proposes the traveling-wave ansatz A = a Jn,m(λ₁z+λ₂t) with Jn,m = sinhm/coshn, taking the amplitude a real (“without loss of generality”) and no carrier phase. From an index-matching argument it announces a catalogue of 49 solution branches, n,m ∈ {−3/2 … 3/2}², offered as ground truth for future PINN benchmarks. The paper solves no closure system for any branch.

§2 · The auditThree defects, one exact certificate

The audit rebuilds everything from scratch. Substituting the ansatz and dividing by A maps the PDE onto rational functions of T = tanh ξ (and W = sech ξ, which is not rational in T); clearing only powers of T and 1−T² — both nonzero on the open domain — turns “is this an exact solution?” into “do all polynomial coefficients vanish?”. A bounded factor-splitting solver then enumerates every solution family of that system, refusing a = 0 and flagging λ₂ = 0. Findings against the paper:

The classification contradicts itself. The paper’s own Eq. (28) derives n = m from its index-matching requirement — then Section 7.3 takes the 7×7 Cartesian product anyway, adding 42 off-diagonal pairs with no justification. Deeper: the argument treats distinct J-functions as linearly independent, but J₂,₀ = J₀,₀ − J₂,₂ (sech² = 1 − tanh²). Index matching is neither necessary nor sufficient: the one bright branch that genuinely closes, (1,0) = sech, is off-diagonal.

The printed residual split is wrong. Eqs. (37)–(38) attach β₃ and β₄ to the wrong field components and leave a complex coefficient outside Re[·]/Im[·]. The corrected split is derived symbolically and proven against F = Fu + iFv on random smooth fields in the test suite. The abstract also counts “eight physical parameters” while listing nine.

“a real without loss of generality” is a loss of generality. A z-dependent carrier phase cannot be gauged away in this equation. Under the paper’s convention no branch retains Kerr nonlinearity (γ is forced to 0 everywhere), and no nonconstant branch tolerates saturation Γ > 0. §9 shows what returns when the phase is restored.

§3 · The survivorsNine pairs, three benchmark-grade profiles

Every family that survives is a reduced model — the closure forces several physical coefficients to vanish. The three smooth, bounded, unambiguous profiles form the main benchmark; singular and unbounded profiles form a separate stress group. §5 · Forward benchmarkCan a PINN reconstruct the verified solutions?

The pilot matrix: 3 branches × 2 closure-respecting parameter sets × 3 methods (fixed weights; gradient-norm adaptive weights; residual-adaptive collocation) × 5 seeds = 90 runs, zero failures. Networks are tanh MLPs in float64 trained on exact initial and Dirichlet boundary data plus the PDE residual only — no interior solution values. Errors are measured on an independent grid; residuals at points never used in training.

Every seed of every cell. The constant and kink branches sit one to two decades below the 10−2 success threshold; the bright sech branch straddles it. Red diamonds: high-fidelity retraining of the sech branch (2.5× steps, 2× collocation points).

§6 · Inverse problemWhat can be recovered — and what provably cannot

g₀, T₂ and α are not separately identifiable. They enter the equation only through c = g₀T₂² and ℓ = (g₀−α)/2. The sensitivity Jacobian of the residual on the exact solution has rank 2 of 3 in (g₀, T₂, α), with an explicit null direction — so recovery is performed in the reduced coordinates, and any claim of recovering all three separately from a single field would be wrong by construction.

Staged recovery (network and parameters trained jointly from sparse noisy field observations plus the residual; positive parameters via softplus, all scaled to O(1)):

Left: median recovery error vs noise at 5% observation density (both branches pooled; γ and, on most branches, the β’s have true value 0 — absolute error shown). Right: recovery vs observation density for the gain/loss stage. Densities covered: 1%, 5%, 10%.

  • Gain/loss stage: ℓ to 0.3–2%, c to 1–7% across 0–5% noise.
  • Nonlinear stage: α₂ to 1–3%; saturation Γ (true 0) pinned to ≤0.04 absolute; Kerr γ correctly discovered as ≈0.
  • Dispersion stage: β₂, β₃, β₄ (all true 0 on these branches) pinned to median absolute error 3.3e-02.
  • Joint 4-parameter stage (c, ℓ, α₂, Γ): median relative error 1.5e-01.

A further audit consequence: on the surviving branches most coefficients are forced to zero, so the paper’s proposed nine-parameter recovery benchmark largely reduces to discovering zeros.

§8 · GeneralizationOne conditioned network across branches

A single PINN taking (z, t) cannot represent multiple solutions at the same coordinates, so a parameter-conditioned network Â(z, t; η) is trained across branches, with η the scaled shape indices, wave parameters and physical coefficients. New evaluation tasks are generated only by re-solving the exact closure constraints at new free-parameter values.

Parameter transfer. Interpolation to unseen in-range parameters partially works (5–25×10−2); extrapolation fails.

Branch transfer. Zero-shot on a held-out branch fails completely (L2RE ≈ 1); 1% of held-out data recovers scratch-level or better accuracy at the same compute budget.

§9 · CodaWhat the paper lost with its phase convention

As a clearly separated optional experiment, the audit was re-run with the carrier ansatz A = a Jn,m(ξ) ei(κz+ωt) over all 49 pairs. The carrier rescues none of the 40 rejected pairs — but on the surviving nine it restores exactly the physics the constant-phase convention destroyed:

  • the classic traveling bright NLS soliton on (1,0): γ = β₂λ₂²/a² (focusing), with dispersion relation κ and group velocity from ω;
  • the traveling dark soliton on (1,1): γ = −β₂λ₂²/a² (defocusing);
  • a Tier-A continuous-wave solution on (0,0) with saturation, fourth-order dispersion and gain/loss simultaneously active — the only full-model solution found anywhere in this study.

All 17 extended families pass the same two verification gates (residuals ≈ 10−51). The verdict: the catalogue’s collapse is caused by the “a real without loss of generality” assumption, not by the equation.

§10 · ReproductionScope, honesty, and exact commands

Everything above is regenerated by the commands below; every experiment skips completed jobs and resumes from checkpoints, so interrupting costs nothing. Raw per-run results, checkpoints, seeds, and environment logs are kept under results/.

# audit + tests + numerical validation
python scripts/run_audit.py --config configs/audit.yaml        # +--extended-phase
python -m pytest tests/ -q
python scripts/run_numerical.py

# forward / inverse / ablations / generalization
python scripts/run_forward.py --config configs/pilot.yaml      # 90-run matrix
python scripts/run_forward.py --config configs/sech_highfidelity.yaml
python scripts/run_forward.py --config configs/stress.yaml
python scripts/run_inverse.py  --config configs/inverse_pilot.yaml
python scripts/run_ablations.py
python scripts/run_generalization.py --config configs/generalization_pilot.yaml

# or the whole pipeline:
python scripts/run_full_benchmark.py --mode smoke|pilot|full

Scope notes. All training ran in float64 on a 4-core CPU; network and collocation sizes are the documented CPU scaling of the recommended settings (configs/full.yaml keeps the 6×64 / 10k-point GPU configuration). Every experiment listed above has been executed at the stated scale; the only configuration not run end-to-end on this machine is the GPU-scale configs/full.yaml. This study tests whether PINNs reproduce independently verified solutions and where they fail; it does not claim that PINNs “work”.
